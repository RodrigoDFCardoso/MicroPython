# Repositório de Códigos MicroPython

Este repositório contém um conjunto de códigos desenvolvidos em **MicroPython** com foco em testes, aquisição de dados, transmissão e visualização em dashboards. Os scripts estão organizados por categoria, conforme as etapas do desenvolvimento e os diferentes dispositivos utilizados.

## 📂 Estrutura do Repositório

### 🔬 Análise de Dados
Contém scripts voltados para **análise de dados** adquiridos durante os testes, visando o desenvolvimento de **dashboards** e apresentação dos resultados de forma visual.

### 🔧 Arduino
Códigos de testes com **sensores conectados à placa Arduino UNO**, utilizados para validação inicial dos sensores e comparação com outros ambientes.

### 💻 BitDogLab
Scripts desenvolvidos especificamente para a **placa de desenvolvimento BitDogLab**, principal plataforma utilizada no projeto.

### 📡 LoRaWAN
Implementação da **aquisição de dados e transmissão via LoRaWAN**, utilizando uma placa de rádio dedicada **acoplada à BitDogLab**. Ideal para aplicações IoT de longo alcance.

### 🌐 HTML
Dashboard desenvolvido em **HTML** para visualização dos dados. Este painel é **disponibilizado na rede pela BitDogLab**, permitindo acesso remoto à interface de monitoramento.

### 🐍 Raspberry Pi Pico
Base de testes e desenvolvimento de códigos usando apenas a **Raspberry Pi Pico**, antes da implementação final na BitDogLab. Utilizado para validação funcional em um ambiente mais controlado.

## ⚙️ Tecnologias Utilizadas

- MicroPython
- Arduino IDE
- HTML/CSS
- LoRaWAN
- Raspberry Pi Pico
- BitDogLab
